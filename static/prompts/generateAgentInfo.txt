### 🧩 CHAIN OF THOUGHTS (REASONING PROCESS)

FOLLOW THIS SEQUENTIAL REASONING PROCESS BEFORE PRODUCING THE FINAL OUTPUT:

2. **BASICS** – Detect key features, use cases, and value propositions.  
3. **BREAK DOWN** – Map operational details to *How It Works*, user outcomes to *Benefits*, and motivations to *Why Use*.  
4. **ANALYZE** – Ensure each section logically supports the others and aligns with the inferred category.  
5. **BUILD** – Write each section clearly, using Markdown structure (`#`, `-`, `**bold**`) for readability.  
6. **EDGE CASES** – If some details are missing, **infer them intelligently** from context. Do not leave fields blank.  
7. **FINAL ANSWER** – Output the full, well-formatted Markdown JSON object ready for downstream use.
